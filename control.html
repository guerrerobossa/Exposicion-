¿Qué son los condicionales?

Los condicionales permiten que un programa tome decisiones. Dependiendo de si una condición es verdadera o falsa, se ejecutará una acción diferente.

Así se ve

let edad = 18;

if (edad >= 18) {
    console.log("Es mayor de edad");
}

Pruébelo

Cuidado con

No confundir el operador de asignación (=) con los operadores de comparación (== y ===).

If

Ejecuta código cuando una condición es verdadera.

If - Else

Permite ejecutar una acción si la condición es verdadera y otra si es falsa.

Ejemplo

let nota = 4;

if(nota >= 3){
    console.log("Aprobó");
}else{
    console.log("Reprobó");
}

¿Qué son los ciclos?

Los ciclos son estructuras que permiten repetir instrucciones varias veces sin tener que escribir el mismo código repetidamente.

Así se ve

for(let i = 1; i <= 5; i++){
    console.log(i);
}

Pruébelo

Cuidado con

Tener cuidado con los ciclos infinitos, ya que pueden bloquear el programa.

Ciclo For

Se utiliza cuando sabemos cuántas veces queremos repetir una acción.

for(let i = 1; i <= 3; i++){
    console.log(i);
}

Ciclo While

Se ejecuta mientras una condición sea verdadera.

let contador = 1;

while(contador <= 3){
    console.log(contador);
    contador++;
}

Uso común

Mostrar listas, recorrer arreglos o repetir procesos automáticamente.
