¿Qué son las variables?

Una variable es como una caja donde podemos guardar información para usarla más adelante en nuestro programa.

Así se ve

let nombre = "Aris";
console.log(nombre);

Pruébelo

Cuidado con

Escribir mal el nombre de la variable o intentar usarla antes de declararla.

Error común

Declarar una variable como nombre y luego escribir Nombre.

Uso correcto

let nombre = "Juan";
console.log(nombre);

¿Qué son los datos?

Los datos son la información que utiliza un programa para realizar tareas o mostrar resultados.

Así se ve

let edad = 17;
let ciudad = "Cartagena";

Pruébelo

Cuidado con

No confundir los números con el texto.

Número

25 es un dato numérico.

Texto

"25" es un dato de texto porque está entre comillas.

Booleano

true y false representan verdadero y falso.

Tipos de datos

Los tipos de datos indican qué clase de información estamos almacenando en una variable.

Así se ve

let nombre = "Aris";
let edad = 17;
let estudiante = true;

Pruébelo

Cuidado con

No mezclar tipos de datos sin saber cómo funciona JavaScript.

String

Guarda texto: "Hola"

Number

Guarda numeros: 50

Boolean

Guarda verdadero o falso: true o false

Operadores de asignación

Los operadores de asignación sirven para guardar valores en una variable.

Así se ve

let numero = 10;
numero += 5;
console.log(numero);

Pruébelo

Cuidado con

No confundir el operador de asignación (=) con los operadores de comparación (== y ===).

Asignación simple

x = 5 asigna el valor 5 a la variable.

Suma y asignación

x += 3 equivale a x = x + 3.

Error común

if(x = 5) asigna el valor en vez de compararlo.
